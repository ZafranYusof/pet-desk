## PetDesk v0.1.0 - Virtual Desktop Pet

### Features
- 3 pet species (Slime, Cat, Ghost) with unique personalities
- 12 unlockable accessories (hats, glasses, bow-ties)
- Full desktop roaming with transparent always-on-top window
- 3 mini games (Catch Food, Memory Match, Quick Tap)
- Day/night cycle based on real clock
- Weather simulation (sunny, cloudy, rainy, stormy, snowy)
- 7 particle effects (sparkles, rain, hearts, fire, snow, zzz, music)
- Pet diary with auto-generated entries from pet's POV
- Desktop notifications when pet needs attention
- 20 achievements with progress tracking
- 7-day login streak daily rewards
- Scrapbook timeline (milestones, firsts, level ups)
- Retro sound effects via Web Audio API
- XP and leveling system with unlock progression
- Tray icon with quick actions
- F10 toggle visibility

### Tech Stack
- Electron 33 (transparent, frameless, always-on-top)
- React 18, Vite 6, Tailwind CSS 3
- Framer Motion animations
- Pure CSS pixel art (no image files)
- Web Audio API (no audio files)

### Install
```bash
git clone https://github.com/ZafranYusof/pet-desk.git
cd pet-desk
npm install
npm run dev
```
